# ПОЛИТИКА ИСПОЛЬЗОВАНИЯ ARABUTHKA

**Дата последнего обновления:** 04 февраля 2026

## 1. Общие положения

1.1. Настоящая Политика использования (далее — «Политика») регулирует порядок использования музыкального стримингового сервиса Arabuthka (далее — «Сервис»), работающего в рамках платформы Telegram.

1.2. Используя Сервис, вы соглашаетесь с условиями настоящей Политики. Если вы не согласны с каким-либо пунктом, пожалуйста, прекратите использование Сервиса.

1.3. Администрация Сервиса оставляет за собой право изменять Политику в одностороннем порядке. Актуальная версия всегда доступна в документации проекта.

## 2. Описание Сервиса

2.1. Arabuthka — это персональная музыкальная библиотека, интегрированная в Telegram, которая позволяет:
- Загружать и хранить собственные аудиофайлы формата .mp3
- Создавать личную коллекцию треков
- Воспроизводить музыку через веб-интерфейс
- Управлять плейлистами и треками
- Использовать функции поиска и сортировки

2.2. Сервис предназначен исключительно для хранения и воспроизведения **собственного** музыкального контента пользователя.

## 3. Правила использования

### 3.1. Разрешенные действия:
- Загрузка музыкальных файлов, на которые вы имеете законные права
- Создание персональной музыкальной библиотеки
- Воспроизведение загруженных треков
- Управление своей коллекцией (добавление, удаление, сортировка)
- Использование функций поиска и фильтрации

### 3.2. Запрещенные действия:
- Загрузка контента, защищенного авторским правом, без соответствующих прав
- Распространение пиратского контента
- Совместное использование аккаунта с другими лицами
- Попытки взлома, обхода защиты или нарушения работы Сервиса
- Загрузка вредоносного ПО, вирусов или других опасных файлов
- Использование автоматизированных средств для массовой загрузки контента
- Злоупотребление ресурсами Сервиса (спам, флуд)
- Загрузка файлов, содержащих незаконный контент

## 4. Авторские права и интеллектуальная собственность

4.1. Пользователь несет полную ответственность за соблюдение авторских прав при загрузке контента.

4.2. Загружая файлы, вы подтверждаете, что:
- Являетесь правообладателем контента, ИЛИ
- Имеете письменное разрешение правообладателя, ИЛИ

4.3. Администрация Сервиса не несет ответственности за нарушение авторских прав пользователями.

4.4. При получении обоснованной жалобы на нарушение авторских прав, контент будет удален без предупреждения.

## 5. Ограничения и лимиты

5.1. **Размер файлов:** Максимальный размер одного файла может быть ограничен техническими возможностями платформы.

5.2. **Объем хранилища:** Общий объем хранилища на пользователя может быть ограничен.

5.3. **Форматы:** Поддерживается только формат .mp3.

5.4. Администрация оставляет за собой право изменять лимиты без предварительного уведомления.
