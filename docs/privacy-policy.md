# ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ ARABUTHKA

**Дата последнего обновления:** 27 февраля 2026

## 1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок сбора, обработки, хранения и защиты персональных данных пользователей сервиса Arabuthka (далее — «Сервис»).

1.2. Используя Сервис, вы соглашаетесь с условиями настоящей Политики и даете согласие на обработку ваших персональных данных.

1.3. Администрация Сервиса обязуется соблюдать конфиденциальность персональных данных пользователей в соответствии с Федеральным законом от 27.07.2006 N 152-ФЗ «О персональных данных» и иным применимым законодательством Российской Федерации.

## 2. Какие данные мы собираем

### 2.1. Данные, получаемые от Telegram:
- Telegram User ID — уникальный идентификатор пользователя
- Имя пользователя (username) — если указано в профиле Telegram
- Имя и фамилия — публичная информация из профиля Telegram
- Язык интерфейса — для локализации сервиса
- Telegram initData — для авторизации через Telegram WebApp

### 2.2. Данные, создаваемые пользователем:
- Музыкальные файлы форматов MP3, WAV, OGG, M4A, AAC — загруженные пользователем треки
- Метаданные треков — название файла, размер, формат, дата загрузки
- ID треков — уникальные идентификаторы в базе данных

### 2.3. Технические данные:
- IP-адрес — для обеспечения работы сервиса и безопасности
- Данные сессии — для поддержания авторизации
- Логи запросов — для мониторинга и отладки системы
- Время активности — дата и время использования функций

### 2.4. Данные, которые МЫ НЕ собираем:
- Номера телефонов
- Email адреса
- Данные банковских карт
- Геолокацию
- Контакты из адресной книги
- Историю переписок

## 3. Цели обработки данных

3.1. Мы используем собранные данные для:
- Идентификации пользователя — через Telegram ID
- Авторизации — проверка initData от Telegram
- Хранения контента — сохранение загруженных треков
- Предоставления функционала — воспроизведение, поиск, сортировка
- Технической поддержки — решение проблем пользователей
- Улучшения сервиса — анализ использования функций
- Обеспечения безопасности — предотвращение злоупотреблений

3.2. Мы НЕ используем ваши данные для:
- Продажи третьим лицам
- Рекламных рассылок
- Профилирования и таргетинга
- Передачи в маркетинговые агентства

## 4. Правовые основания обработки

4.1. Обработка персональных данных осуществляется на основании:
- Согласия пользователя — при начале использования Сервиса
- Договорных отношений — для исполнения условий использования
- Законных интересов — для обеспечения безопасности и работоспособности

4.2. Правовые основания соответствуют статье 6 Федерального закона от 27.07.2006 N 152-ФЗ «О персональных данных».

## 5. Хранение и безопасность данных

### 5.1. Где хранятся данные:
- База данных PostgreSQL — на серверах Railway (США, Европа)
- Файловое хранилище Selectel S3 — для музыкальных файлов
- Серверы Vercel — для веб-приложения
- Серверы Telegram — initData для авторизации

### 5.2. Меры безопасности:
- HTTPS-шифрование — для всех соединений
- Проверка initData — защита от подделки авторизации
- Изоляция данных — каждый пользователь видит только свои треки
- Ограничение доступа — только авторизованные запросы
- Резервное копирование — регулярные бэкапы базы данных
- Защитные HTTP-заголовки — X-Content-Type-Options, X-Frame-Options, X-XSS-Protection
- Rate Limiting — ограничение запросов (100 запросов/15 минут, 10 загрузок/15 минут)

### 5.3. Срок хранения:
- Активные аккаунты — данные хранятся бессрочно
- Неактивные аккаунты — могут быть удалены после 365 дней неактивности
- Логи запросов — хранятся до 30 дней
- Удаленные треки — удаляются из Selectel S3 и базы данных безвозвратно в течение 72 часов

## 6. Передача данных третьим лицам

### 6.1. Мы передаем данные следующим сервисам:

**Railway (хостинг backend и база данных):**
- Telegram ID, метаданные треков
- Необходимо для работы API и базы данных
- Privacy Policy: https://railway.app/legal/privacy

**Selectel S3 (хранилище файлов):**
- Аудиофайлы форматов MP3, WAV, OGG, M4A, AAC
- Необходимо для хранения и потоковой передачи
- Privacy Policy: https://selectel.ru/about/documents/

**Vercel (хостинг webapp):**
- Технические данные (IP, user-agent)
- Необходимо для работы веб-интерфейса
- Privacy Policy: https://vercel.com/legal/privacy-policy

**Telegram:**
- Данные авторизации (initData)
- Необходимо для интеграции с Telegram Bot API
- Privacy Policy: https://telegram.org/privacy

### 6.2. Мы НЕ передаем данные:
- Рекламным сетям
- Аналитическим сервисам (Google Analytics, Яндекс.Метрика и т.д.)
- Социальным сетям
- Брокерам данных

### 6.3. Передача по требованию закона:
Мы можем раскрыть информацию, если это требуется:
- По решению суда Российской Федерации
- По запросу правоохранительных органов в соответствии с законодательством РФ
- Для защиты наших прав и безопасности

## 8. Удаление данных

### 8.1. Как удалить свой аккаунт:
1. Напишите запрос через контакты выше
2. Укажите ваш Telegram ID
3. Подтвердите удаление

### 8.2. Что удаляется:
- Все загруженные треки
- Метаданные из базы данных
- Связь с Telegram ID
- История активности

### 8.3. Что НЕ удаляется:
- Логи запросов (автоматически удаляются через 30 дней)
- Резервные копии (удаляются при следующем цикле бэкапа)

### 8.4. Срок удаления:
До 72 часов с момента подтверждения запроса.

## 9. Файлы cookie и отслеживание

9.1. Мы НЕ используем:
- Cookie-файлы для отслеживания
- Системы аналитики (Google Analytics, Яндекс.Метрика)
- Рекламные пиксели
- Fingerprinting браузера

9.2. Мы используем:
- Session Storage — для временного хранения данных сессии (только в браузере)
- Telegram WebApp Storage — для кеширования настроек

10.2. Если вам менее 13 лет, вы можете использовать Сервис только с согласия родителей или законных представителей.

10.3. Мы не собираем намеренно данные детей младше 13 лет. Если нам станет известно о таком случае, данные будут немедленно удалены.
