# 📖 О ПРОЕКТЕ ARABUTHKA

## 🎯 Концепция

**Arabuthka** — это персональная музыкальная библиотека нового поколения, объединяющая мощь современных облачных технологий с удобством Telegram-интерфейса.

### Что это такое?

Представьте себе музыкальный сервис, который:
- 🎵 **Хранит вашу музыку** в облаке без ограничений
- 🤖 **Управляется через Telegram** — никаких лишних приложений
- 🌐 **Предоставляет веб-плеер** для прослушивания из любого браузера
- 🔒 **Гарантирует приватность** — только вы видите свои треки
- 🚀 **Работает молниеносно** благодаря современной архитектуре

---

## 🎭 Философия проекта

### Для кого создан Arabuthka?

**Для меломанов**, которые:
- Имеют собственную коллекцию музыки в формате MP3
- Хотят слушать музыку везде, но не хотят платить за стриминговые сервисы
- Ценят контроль над своими данными
- Предпочитают простоту и элегантность сложным интерфейсам

### Наши принципы:

1. **Простота превыше всего** — интерфейс интуитивен, функционал очевиден
2. **Приватность по умолчанию** — ваша музыка принадлежит только вам
3. **Независимость** — никаких подписок, рекламы или трекинга
4. **Открытость** — весь код доступен на GitHub

## 🏗️ Архитектура

### Технологический стек

#### Frontend (Веб-приложение)
- **Next.js 14** — современный React-фреймворк
- **TypeScript** — типобезопасность кода
- **Tailwind CSS** — стилизация интерфейса
- **Hosting: Vercel** — быстрый CDN с глобальным покрытием

#### Backend (API-сервер)
- **Node.js + Express** — серверная логика
- **PostgreSQL** — реляционная база данных
- **Selectel S3** — облачное хранилище файлов
- **Hosting: Railway** — автоматические деплои из GitHub

#### Bot (Telegram-интерфейс)
- **Node.js + Grammy** — современная библиотека для Telegram Bot API
- **File Upload Handler** — обработка загрузки аудиофайлов
- **Hosting: Railway** — круглосуточная работа

### Схема взаимодействия

```
Пользователь
    ↓
[Telegram Bot] ← Загрузка треков
    ↓
[Railway API] → PostgreSQL (метаданные)
    ↓
[Selectel S3] ← Хранение .mp3
    ↓
[Vercel WebApp] → Воспроизведение
```

## ✨ Основные возможности

### 🎵 Для пользователей

1. **Загрузка музыки**
   - Отправляйте MP3-файлы боту в Telegram
   - Автоматическое извлечение метаданных
   - Поддержка любых размеров файлов

2. **Воспроизведение**
   - Веб-плеер с интуитивным интерфейсом
   - Потоковое воспроизведение без скачивания
   - Адаптивный дизайн для всех устройств

3. **Управление библиотекой**
   - Просмотр всех треков
   - Поиск по названию, исполнителю
   - Удаление ненужных записей

### 🛡️ Безопасность

- ✅ HTTPS-шифрование всех соединений
- ✅ Авторизация через Telegram initData
- ✅ Изоляция данных между пользователями
- ✅ Защита от несанкционированного доступа

## 🎓 Технические детали

### Почему именно такой стек?

**Next.js 14** выбран за:
- Server-Side Rendering для быстрой загрузки
- App Router для современной маршрутизации
- Автоматическую оптимизацию изображений
- Встроенную поддержку TypeScript

**Railway** выбран за:
- Простоту деплоя из GitHub
- Бесплатный тариф для малых проектов
- Интегрированную PostgreSQL
- Логи и мониторинг из коробки

**Selectel S3** выбран за:
    - S3-совместимое хранение объектов
    - Российский дата-центр с низкой задержкой
    - Гибкое ценообразование и масштабируемость
- Простое API

**Grammy** выбран за:
- Современный TypeScript-first подход
- Мощные middleware для обработки
- Активное сообщество
- Отличную документацию
